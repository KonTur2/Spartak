ПРОЕКТ: Django ERP Система для рыболовной компании
==========================================

ОПИСАНИЕ:
Это веб-приложение на Django для управления предприятием рыболовной отрасли.
Включает модули: учет пользователей с ролями, дашборд директора, управление флотом,
логистика, финансы, добыча ВБР, переработка, сбыт, документы, судоремонт.

ТЕХНОЛОГИИ:
- Python 3.13
- Django 5.1.1
- SQLite (база данных по умолчанию)
- HTML/CSS/JavaScript (шаблоны)
- Bootstrap (предположительно)
- Дополнительные пакеты: Pillow, Whitenoise, django-crispy-forms, django-debug-toolbar

ЗАПУСК ПРОЕКТА:
1. Установите зависимости: pip install -r requirements.txt
2. Примените миграции: python manage.py migrate
3. Создайте суперпользователя: python manage.py createsuperuser
4. Запустите сервер: python manage.py runserver
5. Откройте в браузере: http://localhost:8000

РОЛИ ПОЛЬЗОВАТЕЛЕЙ:
- director (Директор) — доступ к дашборду
- accountant (Бухгалтер) — финансы
- logistician (Логист) — логистика
- fleet_manager (Управляющий флотом) — управление флотом
- crew (Экипаж судна) — просмотр флота

ПРИМЕЧАНИЯ:
- Статическая папка 'static' отсутствует (предупреждение при запуске).
- База данных SQLite создается автоматически.
- Для производства необходимо настроить DEBUG=False, секретный ключ, использовать PostgreSQL и собрать статику.

ТЕКУЩЕЕ СОСТОЯНИЕ ПРОЕКТА (разработка):
==========================================

РЕАЛИЗОВАННЫЕ ФУНКЦИИ:
1. Аутентификация и авторизация:
   - Регистрация пользователей с выбором роли (директор, бухгалтер, логист, управляющий флотом, экипаж).
   - Вход в систему (логин) с проверкой учетных данных.
   - Выход из системы (логаут).
   - Автоматическое перенаправление после входа в зависимости от роли.

2. Ролевая модель:
   - Расширение стандартной модели User через профиль UserRole.
   - Сигналы для автоматического создания профиля при регистрации.
   - Проверка доступа к разделам на основе роли.

3. Интерфейс пользователя:
   - Базовый шаблон (base.html) с навигационной панелью, отображающей доступные разделы.
   - Шаблоны для страниц входа, регистрации, профиля.
   - Дашборд директора с тестовой статистикой (графики, последние заказы, активные задачи).
   - Отдельные страницы для каждого модуля: финансы, логистика, управление флотом, добыча ВБР, переработка, сбыт, документы, судоремонт.

4. Бизнес-логика:
   - Директор видит дашборд с генерацией случайных данных для демонстрации.
   - Ограничение доступа: пользователи видят только свои разделы (например, бухгалтер — финансы, логист — логистику).
   - Система сообщений (Django messages) для уведомлений об успешных действиях и ошибках.

5. Административный интерфейс:
   - Стандартная админка Django для управления пользователями и ролями.

6. База данных:
   - Миграции применены, созданы таблицы для пользователей, ролей и стандартных Django-моделей.

7. Модуль управления флотом (fleet):
   - Создано отдельное приложение `fleet` с моделями: Ship (судно), CrewMember (экипаж), Voyage (рейс), Maintenance (ТО/ремонт).
   - Реализованы CRUD-операции для судов, рейсов, ТО с проверкой прав доступа (только director и fleet_manager могут редактировать).
   - Dashboard флота: список судов с текущим статусом, виджеты статистики, текущие рейсы, последние ТО.
   - Детальная страница судна: карточка судна, список экипажа, история рейсов и ремонтов.
   - Интеграция с модулем accounts: использованы декораторы `role_required` для ограничения доступа по ролям.
   - Шаблоны на Bootstrap, наследование от base.html, адаптивный дизайн.
   - Созданы тестовые данные (судна, экипаж, рейсы, ТО) для демонстрации.
