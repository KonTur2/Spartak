Отчет по реализованному функционалу модуля Fleet

Файл создан: 12.04.2026

1. Назначение модуля

Модуль Fleet реализует учет и управление флотом в ERP-системе. В текущем состоянии он покрывает:
- учет судов;
- учет экипажа;
- планирование и сопровождение рейсов;
- учет технического обслуживания и судоремонта;
- работу с подрядчиками;
- базовые отчеты по эксплуатации флота.

2. Реализованные модели данных

В модуле уже реализованы следующие сущности:

Ship (Судно):
- название судна;
- тип судна;
- номер IMO;
- статус;
- текущее местоположение;
- техническое состояние;
- даты создания и обновления.

CrewMember (Член экипажа):
- пользователь системы;
- должность/звание;
- закрепленное судно;
- дата окончания контракта;
- примечания.

Voyage (Рейс):
- судно;
- экипаж;
- дата выхода;
- дата возвращения;
- район промысла;
- план добычи;
- фактическая добыча;
- описание рейса;
- признак завершения.

Maintenance (ТО/ремонт):
- судно;
- тип ремонта;
- описание работ;
- дата начала;
- дата окончания;
- стоимость;
- статус;
- подрядчик;
- текстовое поле подрядчика;
- документы.

Contractor (Контрагент):
- название организации;
- контактное лицо;
- телефон;
- email;
- специализация;
- примечания.

3. Что реализовано по судам

В модуле доступны:
- просмотр общего списка судов;
- просмотр карточки конкретного судна;
- создание нового судна;
- редактирование существующего судна;
- отображение статуса, местоположения и технического состояния;
- отображение экипажа, рейсов и ремонтов в карточке судна.

Дополнительно реализована логика вычисления актуального статуса судна:
- в море;
- в порту;
- на ремонте;
- выведено из эксплуатации.

Статус рассчитывается с учетом активных рейсов и ремонтов, в том числе для записей без даты окончания.

4. Что реализовано по экипажу

Реализованы:
- список экипажа;
- создание нового члена экипажа с созданием пользователя;
- закрепление сотрудника за судном;
- посадочная ведомость по судам;
- отображение экипажа в карточке судна;
- учет должности/звания и срока контракта.

5. Что реализовано по рейсам

Реализованы:
- создание рейса;
- редактирование рейса;
- завершение рейса;
- выбор судна и состава экипажа;
- указание района промысла;
- указание плановой и фактической добычи;
- просмотр текущих рейсов на дашборде;
- история рейсов в карточке судна.

Бизнес-логика по рейсам уже работает:
- запрещены конфликтующие рейсы одного и того же судна;
- учитываются пересечения рейсов с ремонтами;
- нельзя создать рейс для судна, выведенного из эксплуатации;
- проверяется занятость экипажа в других рейсах;
- завершение рейса сохраняет фактическую добычу и дату возвращения;
- создание и обновление рейсов выполняется атомарно.

6. Что реализовано по ТО и судоремонту

Реализованы:
- список ремонтов и ТО;
- детальная карточка ремонта;
- создание записи о ремонте;
- редактирование записи;
- завершение ремонта;
- переход в судоремонт из общего меню;
- быстрый переход из карточки судна к созданию ремонта.

Поддерживаются типы работ:
- плановое ТО;
- аварийный ремонт;
- текущий ремонт.

Поддерживаются статусы:
- запланировано;
- в работе;
- завершено.

Бизнес-правила по ремонту:
- запрещены пересекающиеся ремонты одного судна;
- ремонт проверяется на пересечение с рейсами;
- аварийный ремонт допускается даже при конфликте с рейсом, с предупреждением;
- после завершения ремонта статус судна пересчитывается;
- активный ремонт без даты окончания корректно считается действующим.

7. Что реализовано по контрагентам

В модуле доступны:
- список контрагентов;
- создание контрагента;
- редактирование контрагента;
- удаление контрагента;
- привязка контрагента к записи ремонта.

8. Что реализовано в интерфейсе

Пользовательский интерфейс модуля Fleet уже содержит:
- дашборд флота;
- список судов;
- карточку судна;
- форму создания/редактирования судна;
- форму создания/редактирования рейса;
- форму завершения рейса;
- список экипажа;
- форму создания члена экипажа;
- список ремонтов;
- форму создания/редактирования ремонта;
- карточку ремонта;
- список контрагентов;
- форму создания/редактирования контрагента;
- посадочную ведомость;
- отчеты по ремонту и по наработке флота.

9. Что реализовано по доступам

Модуль защищен авторизацией и ролевым доступом.

В разных разделах используются роли:
- director;
- fleet_manager;
- dispatcher;
- engineer;
- crew.

Доступ разграничен по операциям:
- просмотр доступен более широкому кругу ролей;
- создание и изменение доступны только ответственным ролям;
- завершение ремонтов и рейсов ограничено по ролям.

10. Что реализовано по отчетности

В модуле уже есть:
- отчет по графику ремонтов и ТО;
- отчет по наработке флота за период;
- посадочная ведомость экипажа;
- блоки сводной информации на дашборде.

11. Что дополнительно уже улучшено

Во время последнего обновления были реализованы дополнительные технические улучшения:
- исправлена обработка открытых рейсов без даты окончания;
- исправлена обработка открытых ремонтов без даты окончания;
- устранен риск сохранения рейса при конфликте занятости экипажа;
- завершение рейса теперь сохраняет фактический улов и дату завершения;
- добавлены автоматические тесты на ключевые сценарии модуля Fleet.

12. Итог

На текущий момент модуль Fleet является рабочим функциональным блоком ERP-системы и уже покрывает основные процессы управления флотом и судоремонтом:
- учет флота;
- учет экипажей;
- управление рейсами;
- управление техническим обслуживанием и ремонтом;
- подрядчиков;
- базовую отчетность;
- ролевой доступ;
- ключевые проверки бизнес-логики.
